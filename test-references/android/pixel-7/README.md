# Pixel 7 native references

Reviewed Android 16 / API 36 Release captures from November 5, 2026. The emulator uses 1080×2400 pixels at 420 dpi; landscape captures use 2400×1080. Reference folders reflect visible appearance.

The final expanded Maestro run passed 18/18 and supplied 24 reviewed captures, including actual portrait/landscape software keyboards, compact folder creation, draft restoration, real Create and compact Cancel, light/dark status contrast and file actions. Additional crop references use a synthetic image selected through Android's real photo picker; crop controls, Done/upload and off-center crop continuity were checked. Completed-queue references cover both orientations and hardware Back. There are 30 Android captures in this update.

All reader data came from a disposable local mock. These references do not establish physical-device, physical-reader or Android foldable-hardware coverage. See `docs/analysis/android-visual-validation-2026-11-05.md` for results, run history and reproduction.
